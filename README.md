# The Daily Bugle - Spider-Man News Website

A news/media platform focused on Spider-Man coverage, built for Problem Statement 6.

## Features

### Core Pages
- **Landing Page**: Dramatic hero section with "Menace or Hero?" headline
- **Home/News Feed**: Breaking news, featured stories, filtered news articles
- **Article Pages**: Full articles with comments, reactions, and related stories
- **Spidey Sightings**: Interactive map showing citizen-reported Spider-Man locations
- **Report Sighting**: Form for citizens to submit Spider-Man sightings
- **Opinion Section**: J. Jonah Jameson's editorial takes with bias comparison
- **Polls**: Interactive voting on Spider-Man-related questions

### Key Features
- 🚨 Breaking news alerts and ticker
- 📰 Biased vs neutral news comparison
- 🗳️ Public opinion polls with live results
- 💬 Comment sections with reactions
- 📍 Citizen journalism sighting reports
- 🔍 Global search functionality
- 🔔 Notifications panel
- ⚖️ Visual bias indicators

## How to Use

1. Open `index.html` in a web browser
2. Start on the landing page - click "READ THE LATEST" or "SPIDEY SIGHTINGS"
3. Navigate using the top menu: HOME | SIGHTINGS | OPINION | POLLS
4. Click articles to read full stories with comments
5. Submit your own Spider-Man sightings
6. Vote in polls to share your opinion
7. Compare biased vs neutral reporting

## Design Philosophy

The website focuses on **media bias** and **public perception** as core themes:
- Same events reported differently by biased vs neutral sources
- Public opinion tracking and visualization
- Citizen journalism and crowd-sourced reporting
- Breaking news alerts and real-time updates

## Technology

- Pure HTML, CSS, and JavaScript
- Responsive design
- Newspaper-inspired aesthetic
- Red/black color scheme matching Daily Bugle branding

## Browser Compatibility

Works in all modern browsers (Chrome, Firefox, Safari, Edge)
